# 功能

面板每一部分做什么，该多长就多长。README 里是短的那份；这里是它变成一本手册之后
被搬过来的部分。

本页链接相对 `docs/`。

## 会话

一个项目就是一个名字加一个目录。新建会话时先挑用什么启动：第一项是项目目录下的一个 shell，
后面是启动配置。会话会自己从 pane 标题取名，手动改过之后自动标题就不再覆盖它。
关掉浏览器标签页，会话毫无察觉。

会话在项目内按紧急程度排序，也可以钉住。每个会话下面还能挂便签终端（截图底部那一条），
同一个目录，用来在 agent 干活的时候顺手 `git status` 一下。

## 状态

形状和颜色同时表意，黑着灯用手机也读得出来。

| | | |
|---|---|---|
| ▲ | **等你处理** | agent 停下来了，要人；排最前面 |
| ● | **在动** | 正在出输出，或者在思考 |
| ✓ | **已完成** | 干完了，或者是一个停在提示符上的 shell |

进程没了另有形状：非零退出是叉，状态码写在提示文字里；干净退出是空心方块；tmux 会话本身
不见了是虚线方块。活着的会话可以手动标成「等你处理」或「已完成」，一直保持到它有新动静为止。

## 状态上报

什么都不装的时候，面板从输出流里判断：刚才有字节出来是*在动*，收到终端响铃是*等你处理*，
pane 回到 shell 提示符是*已完成*。安静的会话不会被当成跑完了。

也就是说**「已完成」是猜不出来的**。agent 干完活并没有退出——它停在自己的提示符上等你——
面板看见的仍然是一个在跑的进程，所以会话会一直是蓝的。新手教程第一件事就讲这个。

**设置 → 状态上报**里每个 agent 一个按钮：Claude Code、Codex、Kimi Code、zcode、opencode。
它把一小段 hook 装进 agent 自己的配置，写之前先把内容原样显示出来，并备份被改的文件。每个
agent 是不同的机制、不同的文件，坏也是各坏各的，所以是一行一个按钮，而不是一个「打开状态
上报」。

面板认识五个，默认只列三个：Claude Code、Codex、opencode。其余的在下面的勾选里打开；已经装
了 hook 的 agent 不管勾没勾都会显示，所以你开过的东西不会被藏起来。其中两个有额外条件：
Codex 要在它里面执行一次 `/hooks` 信任之后才会跑；zcode 的 `hooks.enabled` 为 false 时什么
hook 都不跑，安装会打开它，而卸载只在确认是面板打开的情况下才关回去。hook 读两个由面板注入到
每个会话里的环境变量，然后把状态 POST 回来：

```json
{"sessionId": "…", "state": "waiting"}
```

面板之外启动的会话没有这两个变量，所以同一份全局配置对它们不起作用。卸载时只删掉
vibepanel 自己加的那几条。hook 是一个 `/bin/sh` 脚本，里面调 `curl`；没有 curl 就退回去用
输出流判断。

Claude Code 有四个事件，能报 *working*、*waiting* 和 *done*。Codex 用它自己的 hooks
（`~/.codex/hooks.json`，设了 `$CODEX_HOME` 就在那下面）也能报这三种：开始一轮、跑工具是
*working*，弹出审批是 *waiting*，一轮结束或被打断是 *done*。**Codex 只运行你信任过的
hooks：装好之后在 Codex 里执行一次 `/hooks`。** 设置里那一行会写 Codex 有没有记下这个信任，
以及正在跑的 Codex 会话里有几个真的上报过。以前用 `notify` 装的，再点一次安装就换过来。

没有 hook 上报的 Codex 会话——没装、还没信任、或者 Codex 版本太老——在 Linux 上也不靠猜：
面板顺着这个面板里 `codex` 进程打开的文件找到它自己的 rollout 记录，从里面读一轮的开始、
结束和审批请求。

opencode 装的是一个独立插件，不动它自己的配置文件。

别的 agent 也可以自己 POST 到 `/api/hook/state`，格式见 [docs/api.md](api.md)（英文）。

## 右栏

每个项目两个 tab——**文件**和**笔记**——下半截是一块两个 tab 共用的面板。已经在**笔记**上
的时候再点一下，切到一条不属于任何项目的全局笔记，再点一下切回来。没选项目时也能开全局
笔记——那正是你写「接下来要干什么」的地方。

- **文件**能浏览、能下载。拖到文件树上或者直接拖到终端上就是上传，文件落在会话旁边，
  绝对路径直接替人敲进命令行；截图粘贴进终端也是同一条路。预览按内容嗅探类型而不是看
  扩展名，支持文本、PNG、JPEG、GIF、WebP、AVIF、PDF，上限 8 MiB，长文本按 256 KiB 或
  4000 行截断。

  `.html` 和 `.svg` 会真的画出来，跑在一个 origin 不透明、不执行脚本、策略上完全不允许
  联网的 frame 里，所以项目里的页面碰不到面板的 cookie，也不会趁人看的时候去拉任何东西。
  标题栏里常驻**页面 / 源码**两档；脚本是按文件的开关，每次打开都从关开始。

  文件树上方是一行仓库信息：分支、和上游差多少、有多少没提交，有冲突时多一个词。
  按一下展开全部——改动的文件、最近十五个提交，以及在别的 worktree 里的会话各占一行、
  带自己的分支，全部从磁盘读，不需要任何凭据。里面有一个按钮去问 GitHub 有哪些开着的 PR，
  按分支名对上；它需要面板环境里的 `GITHUB_TOKEN` 或 `GH_TOKEN`，而且只有按了才会联网。

- **笔记**是每个项目一份 markdown，停手就自动保存。

- **下半截**在两个 tab 上长得一样，位置也一样：token 用量在上，机器监控在下。
  按任意一块，它会展开占满右栏，再按一下占满整个窗口。

  token 用量是 agent 自己记下来的账：今天、本周、本项目，以及三十天里按工具拆开的一条。
  数字只来自 Claude Code 和 Codex 自己写的 transcript，不估算，也不换算成钱；
  找不到 transcript 时显示破折号，而不是 0。

  监控是机器的 CPU、内存、磁盘，外加每个会话的 CPU 和内存，按会话的整棵进程树汇总。
  百分比用整机做分母，不是「100% = 一核」。

## 手机端

不是把桌面端缩小，是另一套外壳：独立的命令输入框（对输入法友好）、一排软键
（`esc` `tab` `ctrl`，以及 agent 真正会问的 `y`/`n`/`1`/`2`）、双手柄拖选复制。

加到主屏就是一个 PWA。它的 service worker **故意什么都不缓存**：缓存住的前端会把面板
钉在旧版本上，而「后端可以在浏览器底下随便重启升级」正是这个项目的前提。

面板关着也想收到消息的话，用**设置 → 推送通知**：会话开始等人时往一个 URL POST 一条。
Bark、ntfy、Server酱有现成的模板，别的就自己写请求体，里面可以用 `{session}`、`{state}`、
`{project}`、`{url}`、`{time}`。最多二十个目的地，每个都能单独指定在哪些状态上触发。

## 启动配置

**设置 → 启动配置**：给一套启动方式起个名字——一条 argv，加上启动它时的环境变量。
它存在的理由就是 endpoint：同一个 agent 指向官方、指向公司代理、指向自建网关，
三份配置只差一个变量。

内置四个：shell、`claude`、`codex`、`opencode`，都不能改；复制一份出来，副本里那个 agent
会读的变量名已经填好了。值留空的变量**根本不会设**，所以一份填了一半的配置跑起来和裸终端
里跑一模一样。

**故意没有「API host」这个字段。** endpoint 装在哪个变量里是各家 agent 自己定的，
opencode 干脆没有，它按 provider 在自己的配置文件里选。做成一个字段，面板就得替别人家的
工具维护这份映射。

变量可以标成**密钥**，标了之后它的值再也不会发回浏览器：设置页只显示变量名，和「已经存了
一个」。它通过 tmux 交给进程，不走命令行，所以 `ps` 里看不到，审计日志里也没有。
但它**没有加密**，就是面板数据库文件里的明文，和里面别的东西一样。

会话会记住自己是被哪个配置启动的，所以重启之后恢复它，回来的不只是命令，还有 endpoint。

## 给别人看的屏幕

**分享链接**是一个给另一块屏幕用的地址：`https://<面板>/share/<token>/`。它只打开一个
**分享页面**，除此之外什么都打不开——没有终端、没有写入、没有文件浏览，也没法用一个链接
再生成一个。

分享页面就是一个 HTML 页面，通常让面板自己会话里的 agent 来写，通过一个小 SDK 读面板的数据。
跟它有关的一切都在 **分享** 页——它有自己的地址 `/sharing`，用面板的登录态，设置 → 分享
点过去就是它——是一个列表：每个页面，下面挂着显示它的那些链接。

### 新建、发布、发出去

1. **新建页面。** 起个名字，挑个起点——会话墙、token 消耗、今天做出了什么、手机速览，或者
   空白——空白就是真空白，模版也只是个起点，agent 想推倒重来都行。不指定目录的话，它放在页面
   目录里，叫 `page-<名字>`，并且会变成一个叫 `page-lobby` 的项目。页面目录默认是
   `~/.local/share/vibepanel/pages`（数据目录里，和粘贴的截图放在一起），在页面列表上方那一行
   可以改；你不改，就什么都不存。勾上「建好后开一个 agent 会话」，就会在里面开一个 agent，提示符上
   已经打好了第一句话，你接着写要做成什么。
2. **写。** 这个项目的文件列表上方有 **分享页面**，点开就在终端旁边打开预览：
   - agent 每写完一个文件就重画一次，可以用真实数据，也可以用样例数据——四十个会话、什么都
     没有、没有名字、名字里全是 HTML；
   - 页面抛出的错误列在预览下面，同时写进一个 agent 会去读的文件；
   - **点选**页面上的一个元素，会在 agent 的提示符上打出一行指向它的话，你接着写要改成什么；
   - 放到整个窗口里，可以把手机、笔记本和电视并排着看；
   - 点一下预览就放大到整个窗口，可以在上面切换屏幕，按 Esc 收起。

   在终端里，`vibepanel page check` 会指出页面哪个文件哪一行有问题，`vibepanel page shot`
   会在它要挂的几种屏幕上截图并报告哪里坏了——agent 就是这样检查自己的活的。
3. **发布。** 在预览里、在设置里这个页面那一行，或者在它的目录里跑 `vibepanel page publish`
   都行。发布就是把目录此刻的样子存成下一个版本；不发布，任何链接上显示的东西都不会变。
4. **新建链接**，在页面下面（页面得先发布过）。起名字、给这块屏写个名、选能显示多少、多久
   过期，再按这块屏调一下页面自己的设置。地址**只显示这一次**——复制下来或者直接打开，因为
   面板只存了它的哈希。
5. **在那块屏上打开。** 装完了。

之后都在同一个列表里：

- **查看**（链接那一行的眼睛）会在新标签页里打开这个链接此刻显示的样子，用的是一个十五分钟
  的临时副本。真正的地址没法再显示一次，想看它就用这个。
- 再**发布**一次，所有「跟随发布」的链接下一次轮询就换上了，不用碰屏幕。也可以把某个链接
  **固定**在一个版本上。
- 在预览里**在屏上试看**，会把草稿放到某个链接上十分钟，什么都不做的话它会自己恢复。
- **版本**里列着发布过的每一版，随时可以回滚。
- **打开**会回到这个页面的项目，旁边是预览。目录要是没了——删了、换了机器、数据目录被清了——
  按钮会变成**恢复并打开**，先把已发布的版本写回去；`page-…` 项目被删了的话，也会重新建一个。

**导出**（页面那一行的下载按钮）把已发布的版本存成 zip，没发布过的就导出目录现在的样子；列表
上方的**导入**用 zip 新建一个页面，不会自动发布。命令行里是 `vibepanel page export` 和
`vibepanel page import`。

页面目录要是写不进去——盘没了、数据目录在系统服务的 `/var/lib` 下面——新页面会放到下一个能用
的地方：先 `~/.local/share/vibepanel/pages`，再 `/tmp` 里的一个目录，列表上方那一行会写明用了
哪个、为什么。

页面可以声明几个可调的设置——标题、颜色、阈值——在链接那一行按链接改，屏幕上不用刷新就会变。
每一行还写着此刻有几块屏打开着它。给链接**上锁**，在解锁之前它的页面、版本、设置和试看都改
不了——一堆链接开着的时候，客户正在看的那一块就是不该被手滑改掉的那一块。

给链接写个**屏幕名**——「三楼会议室那块屏」「给客户看的」——它会出现在设置那一行，也会交给页面。
两档详细程度都会带上：它是链接的主人写给站在屏幕前那个人的话，不是面板自己的字。

### 页面能显示什么

数据是面板知道的那些，加上仓库自己说的那些。页面在 `vibepanel.json` 里写明要哪几块，别的
一概不发给它。

**花了多少**：agent 自己记的 token 账，按天、按 agent、按模型、按项目。只有 token，不折算
成钱：价格按模型、按档位、按时间都不一样，拿过期价目表算出来的金额，是一个看起来很确定的
错数。

**做出来什么**：提交数、新增和删除的行数、动过的文件——今天的、一段时间的，还有走势。给了
面板 GitHub token 的话，还有开着的 PR、CI 过没过、今天合了几个。这些是读工作区数出来的，
所以是「现在存在、今天早上还不存在」的东西，而不是谁记得去勾一下的东西。代码行永远是两个
数、绝不合成一个净值：+1200/−800 和 +400/−0 是完全不同的两天，净值却一样。agent 还没提交
的活，这里一概看不见。

**今天怎么过的**：多少个开了工、多少个停下来等人、多少个做完了，以及东西在那儿放了多久才
有人管——按小时或者按天。还有一条「刚刚发生了什么」，那是墙上唯一会动的东西。

另外还有会话和它们的状态、清单进度、机器负载。

### 链接能说多少

范围可以限定成整个面板、一个项目或一个会话，由服务端按链接自己那行强制执行；项目后来删掉了，
链接显示「什么都没有」，而不是退回去显示全部。

生成时选详细程度。**只有数量**（默认）只有形状和数字，一个字都不带；**加上名字**会把会话
标题和项目名也发出去。两档都不会发送路径、工作目录、命令行、主机名和面板自己的 id。名字、
屏幕名、锁、版本和设置都可以事后改，档位和范围不行——想改的时候地址早就躺在别人邮件里了，
把它能看到的东西改宽，拿着地址的人根本不会知道。

链接本身就是凭证，谁拿到谁就能看。每个链接单独吊销，可以设过期时间，生成和吊销都会记进审计
日志。吊销或过期的地址只会打开一个写着「链接已失效」的空白页，面板的东西一样都没有。

页面在沙箱里运行：读不到面板的 cookie 和存储，调不了面板的接口，打不开终端，也连不到任何
别的地址。SDK 会写明*实时*、*重连中*、*已断开*还是*已吊销*，免得一个悄悄卡住的页面看起来像
一台闲着的机器。实现细节见 [share-pages.md](share-pages.md)。

### 以前的看板链接

早先的版本在分享链接上画的是**看板**——一堆组件拼出来的。看板已经删了。升级后第一次启动时，
每个老链接都会指向一个按它原来看板最接近的模版做出来的页面（今天做出了什么、token 消耗、
手机速览或会话墙），已经发布好，目录同样在 `page-…` 下面。挂在墙上的地址照样能用，详细程度、
范围、屏幕名和过期时间都不变。

## 手机上的聊天

会话在等你的时候，可以推到 Telegram、飞书或者微信，你在同一个窗口里回它。设置栏最下面的
**聊天**（或者 `/chat`）是设置它的地方。

**通道。** 每个应用一张卡。Telegram 要一个 @BotFather 给的 bot token；飞书要应用的 id、
secret 和 verification token，卡片上会显示要填进开放平台的回调地址；微信是扫码登录。
每张卡都有一行健康状态，说的是最近一条消息什么时候到的——这是「通了」和「填了」之间唯一的区别。

**隐私。** 在开启某个通道之前，聊天功能不连接任何外部服务：三个接入是自己写的，没有第三方
SDK，打包在二进制里；微信登录的二维码在浏览器里本地生成，截图用的字体也是打包的。第一次开启
通道或高级模式时，面板会说清楚哪些内容会经过外部服务器（会话标题、agent 说的话、要你允许的
命令、屏幕截图；高级模式还有你发的话和会话列表，交给模型服务商），你同意之后才会继续。这个
回答记在服务端，用 API token 也绕不过去。

**配对。** 你没点头之前谁都不能跟面板说话。第一个给机器人发消息的人会收到一个六位配对码，
页面上出现一行「待配对」；让对方把配对码告诉你，在页面上输入。配对的人能查看和操作所有会话。解除拉黑就是删掉那一行，
对方要拿新配对码重新配对；可以给联系人改名（微信不提供名字）。每个人有一个模式：*普通*只收命令和
带编号的回复，*高级*也收整句话。

**你会收到什么。** 每次变化一张卡，永远以会话编号开头：

    ▲ [3] fix tmux · vibepanel
    要你允许 · 2 分钟前 · claude

    Bash: go test ./...

Telegram 和飞书上权限提示带「允许」「拒绝」按钮；微信上回 `y` 或 `n`。回答只对你看到的那条
请求生效：已经答过的旧卡片不会允许下一条请求，对没看过的请求回 `y` 会先把请求给你看。
会话在工作时，能改消息的应用会原地改那张卡；请求答完，按钮就撤掉。微信只能在你最近说过话时
回复；它联系不上你期间在等的会话，会在你下次发消息时先列出来。

**回复。** `3: 你的话`发给 3 号会话，引用它的卡片也一样。没写编号的话发给唯一在等你的那个；
两个都在等的时候会拒绝并列出来——把一个 `y` 打进错误的 agent 是这里唯一不能犯的错。
「切到 3」之后，没写编号的话都发给 3，哪怕别的会话在等（回执会写谁还在等），「不切了」取消；
单独一个「好」仍然给那个在问的会话。`3 继续`、`3号 继续`、`第三个` 也行，「嗯，好的。」这种语音转出来的话也认。每次送达都有一条回执，
写着编号。回「帮助」列出其余的（机器人说中文时命令也是中文：列表、屏幕 3、停 3）：`list`、`screen 3`、`shot 3`（截一张图）、
`open 3`（面板打开那个会话）、`context 3`（最近的对话，两边都有）、`focus 3`、`mute 3 2h`、
`stop 3`（先问你确认）、`usage`、`more`（`more 3` 看那个会话的长消息）。图片带着说明文字一起
送进会话；没有说明时先填在输入框里，等你下一句。

**规则**决定谁收到什么：按项目、工具、状态或消息类型，推给所有人或某一个人，可以设安静时段
（权限请求和提问不受它限制）和截图策略。「试一下」选一个会话，告诉你哪条规则会命中、谁会收到。

**高级模式**在面板自己的目录里跑一个无头的 Claude Code 或 Codex。一句话——「让写文档的那个
加一条 changelog」「上上条那个，允许」——会变成一个动作，凡是要写进会话的都先等你回 `ok`。
`问：3 号在干嘛`用只读工具回答。微信语音到面板时已经是文字；agent 决定往哪发的时候看不到
任何会话的屏幕。有每日预算，页面上显示今天花了多少。

**按键表**是「允许」在每个工具里按什么键。Claude Code 是回车，Codex 是 `y`；其他的照抄
Claude Code，可以改。键名必须是 tmux 认识的，「恢复默认」一键还原。

这里没有群：每个对话都是一个人对一个机器人。

## 第一次打开

没有账号的面板会打印一个一次性 token，粘进去、设个密码，然后教程就开了。

五步，其中两步是真的在做事。它给这台面板设置里勾上的那些 agent 装状态上报——各是各的机制、
各是各的文件，一个一行一个结果——并且提供 Claude Code 其余那几项设置：会话是否镜像到 claude.ai、
Remote Control、提交和 PR 的署名、计费头。每一项都会把「文件里现在是什么」和「会改成什么」
并排列出来，写之前先备份。

关掉之后记在服务端而不是浏览器里，所以在电脑上看过一遍，手机上就不再弹。

## 重启、关机和升级

```sh
systemctl --user restart vibepanel   # 面板消失又回来
tmux -L vibepanel ls                 # 会话一个不少，还在跑
```

面板只是以客户端身份 attach 上去，从不持有会话进程的父 PTY；而且它跑在自己的 socket
（`-L vibepanel`）配自己的配置文件上，所以可以和已有的 tmux 或 zellij 装在一起互不干扰。
重连时浏览器会发现后端换了版本并提示刷新。

**关机是另一回事。** tmux server 就是个普通进程，回滚记录在它的内存里，机器一关两样都没。

面板会把重建一个会话需要的东西记下来：建它时用的命令、目录、名字和排序位置，以及最后
2000 行或 256 KiB 的回滚记录，每 30 秒抓一次，关机时再抓一次。正常关机一行输出都不会丢，
断电最多丢半分钟。开机之后面板会问要不要恢复，一个或者全部，并把每个会话将要执行的命令和
目录列出来。也可以给某个会话单独打开「开机自动恢复」，默认是关的。

**进程回不来。** agent 的上下文活在那个进程和它跟服务商的一段对话里，重跑命令启动的是一个
全新的、什么都不记得的 agent。恢复出来的 pane 会在新进程上方打一条横幅说明这件事，
会话本身还会留一个 `restored` 标记。

**设置 → 更新**去 GitHub 取最新 release，用同一个 release 里发布的 `SHA256SUMS` 校验，
先把新二进制跑一次确认它在这台机器上能启动，再换掉旧的并重启服务，旧的留成 `.old`。
下载在服务端进行，页面睡了或刷新了，回来还是同一条进度条；更新说明在你同意之前就能看到；
有新版本时侧栏会说一声。

面板会自己检查，但只在有人开着它的时候：上次答案超过六小时，就向 `api.github.com` 发一个
只带版本号的请求。没有定时器，没有心跳，没有遥测；没人打开的面板从不去问。这个检查可以在
同一个区块里关掉，按钮照样能用。

它走的是 `api.github.com`，而且没有镜像开关，所以连不上 GitHub 的机器走另一条路：
解开新的发布包，再跑一次 `./deploy/install.sh`，它会沿用现在装着的那种 unit 并重启它。
两种方式下会话都不会跟着重启。

还有两件事的行为值得知道：改过的 tmux 配置要到下一次 `start-server` 才生效，而面板从不杀
自己的 server，所以设置页和 `vibepanel doctor` 会在磁盘上的文件和内存里的设置对不上时说一声；
以及旧二进制会拒绝打开被新版本迁移过的数据库，并把两个版本号都说出来，而不是打开它、
然后悄悄丢掉自己不认识的列。

其他情况看 [docs/runbook.md](runbook.md)（英文），它是按症状组织的。

## 写在文件里的那些设置

**设置 → 这个面板**里可以直接改服务的环境文件：监听地址、域名、TLS 和证书、ACME，以及谁能
访问这个面板。改的就是安装时写的那个文件，注释和注释掉的示例都原样保留，改之前先备份。

这些下次启动才生效，所以重启按钮就在下面一格。重启只是停掉面板让服务管理器拉起新的——只断
连接，会话不受影响，因为进程归 tmux。如果这台机器上没有东西会把它拉起来，按钮会直接告诉你，
而不是把面板停掉。

有两项只显示、不让改。`CLOUDFLARE_API_TOKEN` 是凭据，页面根本拿不到它。
`VIBEPANEL_TMUX_SOCKET` 是把面板和你自己的 tmux 隔开的那一条：换了它，面板就看不见自己的
会话，而它原本管着的那些会继续跑，没有任何东西连着。

## 挂到公网上

面板默认监听 `:18443`，也就是所有网卡，本来就是照着直接面对公网设计的。

所有接口都需要凭据，WebSocket 也一样——它就是终端。例外有三个：健康检查；agent hook 接口，
它收的是注入到每个会话里的令牌；以及分享链接，它收的是分享 token，只在它的页面文件和数据快照这几个 `GET` 上认，
换到别的接口一律 401。

首次启动会把一次性的 setup token 打到控制台：能读到服务端输出的人才有资格认领这个面板，
建好账号之后这个接口就永久关闭。登录失败按来源地址指数退避，`--allow-from` 进一步限制谁
能够到面板。这两者判断的都是 `--trusted-proxies` 说可信的那个地址；没配可信代理时就是
socket 对端，`X-Forwarded-For` 完全不看。

**Passkey** 是加在密码之上的，不会成为唯一入口。WebAuthn 要求 Relying Party ID 是一个
可注册域名，所以 IP 地址无论 TLS 怎么配都注册不了 passkey。`vibepanel doctor` 和登录页
都会说明当前配置支不支持。

**API 令牌**和密码互相独立：改密码会踢掉所有浏览器但不动令牌，反过来也一样。
令牌只在创建时那一次响应里能读到。

**证书**由面板自己管，两条路：

```sh
# 自己的证书，文件变了自动重载
vibepanel --domain panel.example.com --tls files \
          --tls-cert /etc/ssl/panel.pem --tls-key /etc/ssl/panel.key

# 或者自动签发和续期
CLOUDFLARE_API_TOKEN=… vibepanel --domain panel.example.com \
          --tls acme --acme-dns cloudflare --acme-email you@example.com
```

自动证书走 DNS-01，因为 HTTP-01 要占 80 端口；目前接了的 provider 是 cloudflare。
非环回地址上留着 `--tls off` 会在启动时告警。
