# 待办清单

来自 2026-08-26 的一轮使用反馈。按"你能多快看见"排序，不是按难度。

## A — 界面（最先做，因为你现在正开着面板）

- [ ] **A1 终端行的割裂感** — xterm 的 `lineHeight` / `letterSpacing` 没调过，行与行之间有空隙，读起来像被切开。
- [ ] **A2 复制就是复制** — 终端里复制的东西现在要再点一下按钮才进剪贴板。浏览器只在"用户手势"里允许写剪贴板，所以有这一步；但选中本身就是手势，能直接写。
- [ ] **A3 粘贴图片** — 现在粘不进去。要走上传通道：粘贴板里的图片 → 上传到项目目录 → 把路径填进命令行。
- [ ] **A4 右栏四个 tab 空间利用率太低** — 文件/监控/笔记/待办各占一整屏。改成可分屏、可折叠、按内容自适应。
- [ ] **A5 目录选择和新建目录的 UI** — 现在加项目是 `window.prompt` 让你手打路径。后端已经有目录浏览 API，缺的是前端。
- [ ] **A6 icon** — 没有 favicon，没有 PWA 图标，标签页上是一片空白。
- [ ] **A7 整体太丑、太缩** — 密度、层次、留白、配色的一次通盘重做。

## B — 语言

- [ ] **B1 简体中文** — 全站 i18n，跟随浏览器语言，设置页可切。
- [ ] **B2 "状态靠猜"那条提示** — 逻辑是对的（装了 hook 不等于已经上报过），但文案又长又英文，读起来像在怪你。重写，并且降低存在感。

## C — 平台能力

- [ ] **C1 PWA** — manifest + service worker，手机上可"添加到主屏幕"。
- [ ] **C2 通知权限 + 手机推送** — agent 变成"等你处理"时推一条通知。这是这个项目最该有的功能。
- [ ] **C3 每个会话的 CPU / 内存** — 按 tab 看占用，找出跑飞的 agent。
- [ ] **C4 开放 API + API 文档** — 给 agent 用来管理面板本身。REST 已经有了，缺的是稳定契约和文档。

## D — 部署

- [ ] **D1 systemd 高优先级、防 OOM** — `OOMScoreAdjust`、`Nice`，别让内核在内存紧张时先杀它。
- [ ] **D2 开机自启 + 安装脚本流程** — 一条命令装好、设服务、开自启。
- [ ] **D3 也能当普通进程跑** — 不强制 systemd。

## E — 发布

- [ ] **E1 专业易懂的 README** — 中英双份。
- [ ] **E2 推到 GitHub public** — `jiangmuran/vibepanel`。
